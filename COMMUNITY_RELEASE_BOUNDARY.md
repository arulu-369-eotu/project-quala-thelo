# Community release boundary — public-safe notice

**No AGPL license grant is created by this document.** The present repository remains under its root license.

When a separate UQL Community distribution is prepared:

1. Create a new, clean-history repository with only the bounded language reference compiler, examples, conformance tests, and basic local verification. Do not copy the upstream Git history or any other research compartments.
2. Require an explicit source-file allowlist and inspect built wheels, source distributions, test data, and documentation. Reject every path not on the release list by default.
3. Keep proprietary improvements, advanced analysis, operational integrations, private services, protected research, and credentials out of that distribution.
4. Do not include optional authentication services, network calls, royalty routes, remote administration, or special visual assets in the Community compiler.
5. Use an unmodified OSI-approved license only after copyright/third-party rights authorization and legal review. Users of a genuinely open-source Community edition may use it commercially within its license conditions.
6. Keep product names/trademarks separate from rights to copy, fork, modify, or redistribute licensed software. Do not impose additional restrictions contradicting the chosen open-source license.
7. Preserve source version and provenance records; deleting or editing a current file does not remove material already disclosed in earlier public commits and clones.
8. Require reproducibility and tamper tests and independent inspection before a public release is declared.

Release claims must distinguish the clean Community edition from this historical parent project and from separately licensed commercial editions.
