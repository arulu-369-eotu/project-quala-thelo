# Seal of Eotu

![Seal of Eotu](../../citadel-core/uql_compiler/next/assets/seal-of-eotu.jpg)

The user supplied and named this image **Seal of Eotu**. The original is
preserved without editing, cropping, recoloring, redrawing, or generating a
replacement. It is 526 by 526 pixels, JPEG.

SHA-256: `736562814373312a141133bf41a6fe5431bdfd78bce52743332fcae05767df19`.

In this repository it is embedded in the root/core documentation and distributed
as installed package data. Every UQL Evidence Bundle contains its original
bytes as `seal.jpg`, an `identity.json` record and a passport reference. The
bundle manifest binds those bytes along with the computational artifacts.

The seal denotes visual identity. Verification reports continue to state their
own evidence and boundaries. A seal, image hash or displayed passport is not a
cryptographic signature, physical security mechanism, attestation or independent
certification. The asset is provided under this repository's existing governing
terms; no new third-party rights claim or registration claim is made here.
